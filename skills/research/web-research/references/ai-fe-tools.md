## Recommended combos

1. **Vibe coding**: v0 → components → Cursor/Claude Code refine
2. **Daily driver**: Cursor (or VS Code + Cline) + Copilot
3. **Rapid MVP**: Bolt.new or Lovable → deploy
4. **AI feature in web app**: CopilotKit (React) or Dify backend
5. **Screenshot → code**: screenshot-to-code → paste into Cursor
